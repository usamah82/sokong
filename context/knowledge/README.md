# Knowledge

| Kind | Path | Write one when |
|---|---|---|
| How-to | `how-to/` | A procedure will be repeated and the steps fit on a page |
| Postmortem | `postmortems/` | Something broke and the cause should outlive the incident chat |
| ADR | `../decisions/` | A choice would be expensive to reverse |

Do not copy an ADR into a how-to. Link it. A how-to says how. An ADR says why. A postmortem says what happened.
